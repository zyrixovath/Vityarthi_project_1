# Simple CLI To-Do List

A lightweight, interactive command-line application written in Python to help you manage your daily tasks. 

## 🚀 Features

* **View Tasks:** See a numbered list of all your current tasks.
* **Add Tasks:** Quickly add new tasks to your to-do list.
* **Delete Tasks:** Remove completed or unwanted tasks using their assigned number.
* **Flexible Input:** Navigate the menu using numbers (1-4) or by typing out the command (e.g., "add a task").

## 📋 Prerequisites

All you need is Python installed on your computer. This script runs on standard Python 3 and requires no external libraries or dependencies.

* [Python 3.x](https://www.python.org/downloads/)

## 🛠️ How to Run

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/zyrixovath/Vityarthi_project_1.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Vityarthi_project_1
   ```
3. Run the Python script:
   ```bash
   python main_file.py
   ```
   *(Note: Replace `main_file.py` with whatever you named your Python file!)*

## 💻 Usage Example

When you start the application, you'll be greeted with a menu:

```text
-------------------------
      MY TO-DO LIST
-------------------------
1. View my tasks
2. Add a new task
3. Delete a task
4. Quit
-------------------------
Choose an option (1/2/3/4): 
```

Simply type the number corresponding to the action you want to take and press Enter.
